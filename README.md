# My First Docker Image with R 🐮

A Docker image based on [`rocker/r-ver:4.6.2`](https://rocker-project.org/) that installs the [`cowsay`](https://cran.r-project.org/package=cowsay) package and prints a message to the terminal when run.

This is a practice project for learning how to create, build, and run Docker images with R.

## Requirements

- [Docker](https://docs.doc
